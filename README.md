# Sorting · 排序算法学习与练习

根据《王道考研·数据结构》第八章“排序”相关内容，使用 C++ 实现排序算法，用来加强记忆、理解算法过程并提高编码熟练度。

代码包含中文注释，以及时间复杂度、空间复杂度、稳定性等学习笔记。本仓库是个人学习练习记录，后续可继续补充和完善。

## 运行方式

1. 在 Visual Studio 中安装“使用 C++ 的桌面开发”工作负载。
2. 打开 `Sorting.slnx`，或直接打开 `Sorting/Sorting.vcxproj`。
3. 项目当前使用 MSVC `v145` 工具集和 C++20；若本机工具集版本不同，可在项目属性中调整平台工具集。
4. 编译并运行程序，查看排序演示结果。

`main()` 当前演示堆排序和计数排序。其他算法的调用保留为注释，可按需取消注释，建议每次运行一种算法以方便观察。

## 当前练习说明

- 源文件保留原有 GBK 编码，阅读时请选择相应编码，以正确显示中文注释。
- 快速排序、归并排序和计数排序的输出循环目前固定为 10 个元素；归并排序的辅助数组也固定为 10 个元素。
- 堆排序采用从下标 1 开始的数组，下标 0 不参与排序；打印的是依次取出的最大值，因此输出为降序，最终数组为升序。
- 计数排序要求输入为非负整数，且每个值小于参数 `k`，当前计数数组容量为 1000。演示随机数范围为 1～100，而当前调用传入 `k = 100`，该范围不匹配仍待完善。
- 基数排序尚未实现，其他实现也可继续补充边界情况验证。

## 学习目标

- 熟悉各类排序算法的核心步骤与代码写法。
- 理解时间复杂度、空间复杂度与稳定性的差异。
- 通过反复实现和调试，加强考研知识点的记忆与应用能力。
